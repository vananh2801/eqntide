========================================================================
             EQNTIDE - WINDOWS RELEASE PACKAGES (x64)
========================================================================

SYSTEM REQUIREMENTS:
- Operating System: Windows 10 (64-bit) or Windows 11 (64-bit).
- Office Suite: Microsoft Word or WPS Office.

------------------------------------------------------------------------
OUTPUT: dist/windows/<version>/ (version read from Cargo.toml)

INSTALLATION PACKAGES:

1. EqnTide-<version>-Setup.exe  (RECOMMENDED FOR USERS)
   - Standard 1-click Windows Setup installer (NSIS).
   - Automatically installs the application on your computer.
   - Automatically loads the EqnTide.dotm add-in into Word's STARTUP folder
     (VBA .dotm only; requires testing on actual Word versions).
   - Automatically registers the add-in for WPS Office.
   - Automatically creates Desktop and Start Menu shortcuts and registers
     the Uninstall entry in Windows Settings.

2. eqntide-native-preview-<version>-x86_64-pc-windows-msvc.zip (PORTABLE / NO INSTALL REQUIRED)
   - For users who want to run directly without an installer.
   - Includes:
     + eqntide-desktop.exe (Rust Desktop GUI)
     + eqntide-cli.exe (CLI & Bridge Server)
     + word-template/EqnTide.dotm (Word Template Add-in)
     + wps-addin/ (WPS Office Add-in)
     + start-server.bat, install-addins.bat, scripts/install-addin.ps1

Word uses only the VBA .dotm template; there is no Word Web Add-in or Word on the Web support.
The installer automatically starts the background bridge at installation and sign-in; WPS continues to use the JS Add-in.
