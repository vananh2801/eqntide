========================================================================
             EQNTIDE - WINDOWS RELEASE PACKAGES (x64)
========================================================================

YÊU CẦU HỆ THỐNG:
- Hệ điều hành: Windows 10 (64-bit) hoặc Windows 11 (64-bit).
- Bộ ứng dụng văn phòng: Microsoft Word hoặc WPS Office.

------------------------------------------------------------------------
ĐẦU RA: dist/windows/<version>/ (version lấy từ Cargo.toml)

CÁC GÓI CÀI ĐẶT:

1. EqnTide-<version>-Setup.exe  (KHUYẾN NGHỊ CHO NGƯỜI DÙNG)
   - Bộ cài đặt 1-click chuẩn Windows Setup (NSIS).
   - Tự động cài đặt ứng dụng vào máy tính.
   - Tự động nạp file Add-in EqnTide.dotm vào thư mục STARTUP của Word
     (chỉ dùng VBA .dotm; cần kiểm thử trên phiên bản Word thực tế).
   - Tự động đăng ký Add-in cho WPS Office.
   - Tự động tạo icon trên Desktop, Start Menu và đăng ký mục gỡ cài đặt
     (Uninstall) trong Windows Settings.

2. eqntide-native-preview-<version>-x86_64-pc-windows-msvc.zip (GÓI PORTABLE / KHÔNG CẦN CÀI ĐẶT)
   - Dành cho người muốn chạy trực tiếp không qua trình cài đặt.
   - Chứa đầy đủ:
     + eqntide-desktop.exe (Rust Desktop GUI)
     + eqntide-cli.exe (CLI & Bridge Server)
     + word-template/EqnTide.dotm (Template Add-in cho Word)
     + wps-addin/ (Add-in cho WPS)
     + start-server.bat, install-addins.bat, scripts/install-addin.ps1

Word chỉ dùng template VBA .dotm; không có Word Web Add-in hay Word on the Web.
Bộ cài tự bật bridge nền khi cài và khi đăng nhập; WPS tiếp tục dùng JS Add-in.
