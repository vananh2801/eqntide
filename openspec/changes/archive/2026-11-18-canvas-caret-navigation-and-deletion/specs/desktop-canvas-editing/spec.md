# Spec Delta

## Purpose

Defines predictable, single-step horizontal caret navigation, empty token pruning, and two-step selection-first structural deletion on the desktop Equation Canvas.

## ADDED Requirements

### Requirement: Single-step horizontal caret navigation without redundant boundary stops
Pressing `ArrowLeft` or `ArrowRight` on the Equation Canvas SHALL advance the caret by one visible character, delimiter, or structural slot boundary per keystroke, skipping redundant coincident stops generated by wrapper containers and adjacent token edges.

#### Scenario: Navigating flat expression takes one keystroke per character or operator
- **WHEN** the equation contains `x+1` and the caret is at the start or inside `x`
- **THEN** each `ArrowRight` press moves past exactly one visible symbol (`|x+1` -> `x|+1` -> `x+|1` -> `x+1|`) and `ArrowLeft` reverses in the same single steps

#### Scenario: Navigating across fraction and script slots does not stall on wrapper rows
- **WHEN** the equation contains `\frac{1}{2}` or `x^{2}`
- **THEN** pressing `ArrowRight` from the end of the numerator moves directly to the start of the denominator on one keystroke, and pressing `ArrowRight` from the end of the denominator or superscript moves directly after the structure on one keystroke

#### Scenario: Navigating across fenced expressions distinguishes inside from outside in one step per boundary
- **WHEN** the equation contains `(x)`
- **THEN** `ArrowRight` steps sequentially across `|(x)` -> `(|x)` -> `(x|)` -> `(x)|` without pausing multiple times at the same visual edge

### Requirement: Empty token cleanup on character deletion
When `Backspace` or `Delete` removes the final remaining character of a token element (`mi`, `mn`, `mo`, `mtext`, `ms`), the editor SHALL remove the empty token node from its parent row instead of retaining a zero-character token node.

#### Scenario: Deleting the only digit in a fraction denominator leaves a true empty slot
- **WHEN** the equation is `\frac{1}{2}` and the user places the caret after `2` and presses `Backspace`
- **THEN** the denominator becomes structurally empty (`□`) with no lingering empty `<mn>` child node, and the LaTeX output updates accordingly

### Requirement: Selection-first Backspace and Delete in empty structural slots
When the caret is inside an empty editable slot of a non-table structure (`mfrac`, `mroot`, `msqrt`, `msub`, `msup`, `msubsup`, `munder`, `mover`, `munderover`, `menclose`, or a fenced expression) with no active selection or command buffer, pressing `Backspace` or `Delete` SHALL select the enclosing structure on the first press, and pressing `Backspace` or `Delete` again SHALL delete the selected structure as a single undoable edit.

#### Scenario: Backspace in an empty fraction denominator selects then deletes the fraction
- **WHEN** the equation contains `\frac{1}{□}` with the caret inside the empty denominator and the user presses `Backspace`
- **THEN** the first `Backspace` selects the entire `\frac{1}{□}` structure, and a second `Backspace` removes the fraction completely (undoable in one step)

#### Scenario: Delete in an empty structural slot selects then deletes the structure
- **WHEN** the caret is inside an empty slot of `x^{□}`, `\sqrt{□}`, or `(□)` and the user presses `Delete`
- **THEN** the first `Delete` selects the entire enclosing structure, and a second `Delete` removes it

#### Scenario: Backspace in a nested empty slot selects the immediate enclosing structure
- **WHEN** the equation contains `1 + \frac{2}{□}` or `\sqrt{\frac{1}{□}}` and the caret is in the empty denominator `□`
- **THEN** pressing `Backspace` selects the inner `\frac` rather than deleting the outer expression

### Requirement: Boundary navigation at start or end of non-empty structural slots
When the caret is at the start (`offset == 0`) of a non-empty structural slot on `Backspace`, or at the end of a non-empty structural slot on `Delete`, the editor SHALL step to the adjacent stop in that direction rather than deleting or selecting the structure.

#### Scenario: Backspace before content in a fraction denominator moves to the end of the numerator
- **WHEN** the equation is `\frac{1}{2}` with the caret immediately before `2` and the user presses `Backspace`
- **THEN** the caret moves to the end of the numerator (`1|`) without modifying or selecting the fraction

#### Scenario: Delete after content in a fraction numerator moves to the start of the denominator
- **WHEN** the equation is `\frac{1}{2}` with the caret immediately after `1` and the user presses `Delete`
- **THEN** the caret moves to the start of the denominator (`|2`) without modifying or selecting the fraction
