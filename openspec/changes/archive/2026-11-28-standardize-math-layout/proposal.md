# Proposal

## Why

EqnTide's box layout engine (`src/render/layout/`) already implements core rules from *The TeXbook* Appendix G and OpenType `MATH` (style contexts, stacked fractions, script shifts, italic correction, and math kerning), yet several areas still rely on hardcoded constants or style-blind spacing. Notably, [`Layout::spacing`](file:///home/vananh2801/Documents/mathtype-convert/eqntide/src/render/layout/row.rs) ignores `MathContext` so nested sub/superscripts (`x^{a+b}`) receive full display-style operator padding, the mathematical axis (`0.258`) is duplicated as a hardcoded `AXIS` constant instead of reading `MathConstants::axis_height`, and `MathConstants` omits the remaining OpenType `MATH` fields needed for subsequent layout standardization phases.

## What Changes

- **Extend `MathConstants` in `src/render/font.rs`**: Extract the remaining OpenType `MATH` table constants from `STIXTwoMath-Regular.ttf` (script drops/limits, display operator minimum height and limit gaps, accent base height, overbar/underbar gaps/thicknesses/ascenders, and skewed fraction gaps) alongside sensible STIX2 defaults.
- **Unify math axis lookups**: Remove the hardcoded `AXIS` constant in `src/render/layout/mod.rs` and read `self.font_set.constants().axis_height` consistently across all layout modules (`bigop`, `delimiter`, `enclosure`, `fence`, `integral`, `matrix`, `row`, `script`).
- **Style-aware inter-atom spacing (TeXbook Ch. 18 / Appendix G Rule 20)**: Pass `MathContext` into `Layout::spacing` so `Script` and `ScriptScript` levels suppress `MED` (`Bin`) and `THICK` (`Rel`) spacing and apply compact TeX script-level spacing while keeping full `Display`/`Text` spacing unchanged.
- **Selective font-fit alignment & visual verification**: Keep intentional MathType/OMML parity choices (full-size fraction parts in Display/Text, continuous delimiter stretching, custom arrow/contour-integral assembly) untouched, and validate all rendered outputs against `STIXTwoText` + `STIXTwoMath` via `tests/export_verification.rs` and `tests/TESTING.md` AI visual inspection.

## Capabilities

### New Capabilities
- `math-box-layout`: Style-aware horizontal atom spacing, unified OpenType `MATH` axis alignment, and font-appropriate TeX Appendix G layout rules while preserving MathType/OMML parity.

### Modified Capabilities
- `math-font-backend`: Extend `MathConstants` with additional OpenType `MATH` table fields extracted from `STIXTwoMath-Regular.ttf` while keeping existing constants, glyph metrics, and outlines invariant.

## Impact

- Affected crates/modules: `src/render/font.rs`, `src/render/layout/{mod,row,bigop,delimiter,enclosure,fence,integral,matrix,script}.rs`.
- Public API impact: `MathConstants` gains new `pub` fields (additive; constructed only internally in `src/render/font.rs`, with `Default` implemented).
- Test & verification impact: Unit tests in `src/render/font.rs` and `src/render/layout/row.rs`, plus visual inspection sheets generated by `tests/export_verification.rs` (`target/test_exports/visual/`).
